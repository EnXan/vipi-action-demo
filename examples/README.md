# Sample images

`visible-injection.png` and `hidden-injection.png` are copies of VIPI's
[sample images](https://github.com/EnXan/VIPI/tree/main/examples) and contain a
prompt injection; provenance and licenses are listed in
[their README](https://github.com/EnXan/VIPI/blob/main/examples/README.md).
`benign.png` is benign and comes from vipi-action's
[test images](https://github.com/EnXan/vipi-action/tree/main/tests/images)
(VIPI evaluation dataset `984da6cacfba1bb3`, Apache-2.0).
